# Student Performance Analysis

## About
A beginner Data Science project that analyzes student marks and grades using Python.

## Technologies
- Python
- Pandas
- Matplotlib

## Features
- Calculate total marks
- Calculate average marks
- Assign student grades
- Identify top-performing students
- Visualize student performance

## Dataset
Contains sample marks of 8 students in Maths, Science and English.
